# ⚽ Brazilian Football Players Ranking

Um projeto desenvolvido para consumir, analisar e exibir dados e estatísticas de futebol utilizando uma API de futebol. 

## 📖 Sobre o Projeto
Este projeto tem como objetivo realizar requisições a uma API de futebol para obter dados detalhados de jogadores brasileiros e criar um ranking de forma usando cálculo próprio baseado nas estatísticas.

## 🚀 Funcionalidades
- Autenticação e conexão com a API-football via API Key.
- Extração de dados JSON com informações detalhadas de jogadores.
- Histórico de estatísticas por temporada (Gols, Assistências, Cartões, etc).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** JAVA
- **Formato de Dados:** JSON
- **Versionamento:** Git e GitHub
